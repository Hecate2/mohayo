# 摸哈游（Mohayo）：区块链回合制 MMO 玩法策划文档

> 版本：v0.1（核心玩法梳理稿）
> 定位：纯区块链（EVM）后端 + 文字聊天软件（Discord / Telegram 等）作为客户端的「大型多人在线」回合制游戏。
> 配套文档：`technical-design.md`（技术实现设计）

---

## 1. 产品概述

### 1.1 一句话定位
「在群聊里组队打地下城」——玩家不需要打开任何游戏客户端，只需在 Discord / Telegram 群里发文字指令，由区块链智能合约权威地驱动一场多人在线回合制 RPG。

### 1.2 核心体验
- **聊天即游戏**：所有操作（创建角色、开房、加入、排技能、结束回合、逃离）都是一句群聊指令。
- **链上权威**：胜负、收益、道具归属全部由合约结算，无法作弊或回滚。
- **混乱即乐趣**：不保证队员每回合都可靠排好技能，空过一回合、乱序、临时加入都是设计的一部分。
- **休闲的冒险体验**：强者也不能保证必胜，弱者也不必败。操作简单但现场混乱。不恶性比拼等级实力。

### 1.3 四层对象模型
```
角色(Character) → 房间(Room) → 地下城(Dungeon，按难度分级) → 战斗(Battle) → 回合(Turn)
```
- 一个 **角色** 可被其拥有者带入任意 **房间**。
- 队长开房时选定一个 **难度等级**，房间即绑定该等级对应的 **地下城**。
- 一座 **地下城** 由若干场 **战斗**（子关卡）串行组成——「打一整座地下城」=「连打多场不同的战斗」。
- 每场 **战斗** 内部按 **回合** 推进。

## 2. 角色系统

### 2.1 四项基础属性（Stats）
| 属性 | 作用 |
|------|------|
| 物理攻击 | 物理类技能的伤害来源 |
| 魔法攻击 | 魔法类技能的伤害来源（通常同时消耗魔素） |
| 生命 | 血量上限；归零即被击败 |
| 敏捷 | 决定每回合的**行动顺序**（敏捷高者先动）；可附带闪避/命中修正 |

最终属性值 = `f(职业基础, 种族上限修正, 等级成长, 词条加成)`。

### 2.2 职业（Class）
- 创建角色时**唯一可由玩家自主决定**的字段。
- 每个职业自带：
  1. **若干职业特有技能**（初始即拥有，可随等级解锁更多）；
  2. **职业词条加成倾向**（例如「剑士」倾向物理/生命词条，「黑魔法师」倾向魔法/魔素相关词条）。
```
- **首版五大职业**（技能命名见 `content-design.md` §4；**每职业 3 个自带技**；数值由数值策划填充）。每个职业都有一个**单刷时暴露的逆天缺点**（详见 `content-design.md` §4.0 缺点表）——职业互补即社交设计：
  - **黑魔法师**：多目标魔法输出——**唯一的常规输出是消耗自身生命的多段攻击**（献祭）；终极技「爆裂魔法」倾泻巨量魔素对全体敌人造成巨大伤害，**施放后自身眩晕躺倒数回合**；黑幕降低敌方全体命中。单刷=自杀式职业，需要白魔法师续命；
  - **白魔法师**：治疗与辅助——较弱的多目标攻击（光弹）、治疗+**为房间魔素池产魔素**（圣泉，一技能两用）、**召唤无嘲讽能力的己方假目标**（替身人偶）；自身几乎没有攻击力，天生要跟队；
  - **守卫**：护盾与嘲讽——盾墙承伤（§4.8）、**回避**只提升自身回避（§4.9 命中管线，无减伤——引擎避免属性乘区，见 `content-design.md` §10.1）、**盾击单体攻击+概率眩晕+嘲讽目标**；防御全给自己、输出垫底；
  - **剑士**：AP 单体爆发——快速剑三连攒点、斩铁剑大 AP 稳定重击、一闪低 AP 难命中但命中即大伤害（单级随机，无需暴击原语）；AP 起手空窗+循环依赖，零防御零 AoE；
  - **火枪手**：弹药型单体输出——**射击技能消耗弹药道具**（铅弹/龙击弹两档，按发付费，§2.5.2/§7.2）；「鹰眼」空放一整回合，换下一回合自己的所有技能绝对命中（§4.9）——左轮弹雨命中率不高，与鹰眼构成「瞄准后弹雨全中」的核心循环；弹尽=空手；
  - （更多职业经 Registry 追加。）
```

### 2.2.1 种族（Race）
- **创建时随机确定，永久不可修改**（与词条同属「命运的抽签」——想换种族只能用重生卷轴整体重建角色）。
- **种族影响四项属性的上限**：每个种族对各属性上限有独立的修正系数（例如兽人抬物理攻击上限、压魔法攻击上限；精灵抬敏捷/魔法、压生命）。种族决定「这辈子的天花板」，职业与词条决定「如何抵达」——同一职业在不同种族下是不同的养成路线。
- **种族特有技能**：除人类外的每个种族自带种族技能（随种族绑定，与职业技能并列持有，创建即拥有）。
- **三层稀有度（用户定案）**：**常见**（人类/兽人/巨人/矮人，合计 ≈85%）——上限修正大起大落，1 个常规种族技（人类换自选 +2）；**略微稀有**（精灵/龙人，合计 ≈12%）——上限修正**降幅收窄** + 1 个**强化**种族技（精灵「暴风术」、龙人「龙鳞」）；**最稀有**（天使/恶魔，合计 ≈3%）——上限**只升微降** + **双种族技**（天使「圣愈之光+天使雷击」、恶魔「汲魂+深渊低语」）。具体权重见 §11 数值层。「天生资质碾压」是**设计意图**：被碾压者的补偿是 D1 保底体验与「下个号可能天选」的抽签期待——稀有度 × 强度的乘积守恒由数值层校准，不破坏 §3.1 胜率标定。**概率压低的动因（用户定案）**：职业适配与技能选择已退出精品概率漏斗（玩家先定职业 + 重掷放弃错配种族 + 自选技无门槛，`content-design.md` §9 重构），稀有的对价只剩概率；且**角色可出售**——天选血脉的稀缺度必须让批量刷号的期望成本压得住售价（§7.4/§7.5）。
- **人类 = 无种族技能，但自选更多**：人类没有种族特有技能，各属性上限采用均衡基准（无修正），补偿是**从自选技能池多自选 2 个技能**（职业角色 1 个 → 人类 3 个）——与无职业路线同构的「自由换强度」哲学。
- **与无职业路线的叠加**：人类 + 无职业 = 最大化自由定制（自选技数量叠加），但属性双弱——「杂而弱 vs 专而强」的极端实验路线。
- 种族与职业、词条一样是**随机+不可改**的抽签维度：硬极品角色的定义为「**稀有种族 × 传说档词条**」（职业适配由玩家重掷筛选保证，不计入随机维度，`content-design.md` §9），重生卷轴的重掷期望成本锚定仍成立（种族只是多了一维随机）。
- **怪物的种族（风味层，不影响怪物自身）**：敌人模板也带种族标签，但**不改变怪物的任何属性与技能**（模板数值照常填写）。它唯一的作用是作为**玩家技能种族修正的查表键**——官方可在任意技能上单独登记「对某种族伤害 ×1.2 / ×0.8」之类的修正（技术设计 §2.5.2）。怪物种族在战报中**默认不播报**（「暗藏」），但链上数据本身公开——读链的玩家可提前得知 Boss 种族并选用带修正的技能，这是允许的信息博弈。
- **首版八种种族**（常见：人类/兽人/巨人/矮人；略微稀有：精灵/龙人；最稀有：天使/恶魔）的命名、种族技与上限倾向详见 `content-design.md` §3；敌人种族标签与克制系技能见同文档 §5/§8。

### 2.3 词条（Affix）
- 角色创建时**全部随机生成**，玩家不可选。每角色词条条数：**3~5 条**（数值层定）。
- **词条是方向 × 档位的复合抽签（用户定案：有好有坏，甚至纯粹坏）**：每条词条先掷**方向**（正面 ≈70% / 双刃 ≈18% / 负面 ≈12%），抽中具体词条后再掷**档位**（1~5 级长尾：≈45% / 30% / 16% / 7.5% / **1.5%**——**传说档在极小概率下带来非常显著的加强或削弱**）。正面如「+12% 物理攻击」，双刃如「物攻↑ 但受到的伤害↑」，负面如「生命上限−X%」「每回合魔素池增量−1」。命名与完整词条表见 `content-design.md` §6。
- **不可单洗**：词条只能随**整体重掷**消散——命运骰子（词条+种族全重掷）/ 重生卷轴（整个角色重建），不存在单条替换或洗练。负面词条是命运抽签的一部分，明码标价的救赎只有重抽——「洗负面」与「追正面」两种动机都汇入重掷道具消费，价格锚（§7.4）双重强化。全负面词条触发无数值的隐藏称号「天弃者」（`content-design.md` §6.4）。
- 种族会**偏向**某种词条的出现概率——偏向作用于词条**类型**（兽人更易出物理系），**不偏向方向的好坏与档位高低**：负面词条对所有种族一视同仁，命运面前血脉平等（数值层定）。
- **首角色重掷包**：每个玩家的**第一个角色**创建时直接附带**数次（例如 3 次）免费重掷**的机会，可连续使用直到满意或用尽；重掷后必须接受新结果，不可回退到之前的结果。不做词条保底——随机到什么全凭运气，但新手有足够的重掷次数自行「抽卡」。非首角色无免费重掷。**重掷不仅重掷词条，也重掷种族**（玩家先定职业、重掷后按协同矩阵决定停手，`content-design.md` §9）。

### 2.4 等级（Level）
- 等级参与属性公式，是成长主线；**属性成长随等级收益递减**（对数型曲线），高等级解锁的更多是外观、称号与高难度资格，而非碾压性数值。
- **等级有硬上限**（例如 50 级，官方可调）。等级上限与递减收益共同保证：付费堆等级的边际收益快速衰减，顶配角色之间数值差距有限。
- **升级消耗游戏币**（无其他门槛）。由于等级有上限且递减，「充钱直升」最多买到上限等级——而上限等级只是挑战最难地下城的**入场券**，不是胜利保证（见 §3.1 难度设计原则）。
- **每 24 小时可加入地下城的次数有上限**（官方可调）；存在**挑战券**道具，使用后可无视当日次数限制强行进入（挑战券消耗性的稀缺度由获取难度控制）。
- 等级提升不改变已锁定的「自选技能池自选技」与词条（词条在创建时定型）。
- **角色履历**：链上为每个角色永久记录履历（累计场次、击杀、治疗量、被救援次数、最高通关难度、称号）。履历**不提供任何数值**，是纯情感与荣誉载体——让角色成为「我的角色」而非耗材。角色所有权转移后等级按 §7.4 规则处理，**履历随角色保留**。

### 2.5 技能体系
角色技能由三部分组成：
1. **职业技**：由职业决定，随等级解锁。
2. **种族技**：由种族决定（人类没有种族技，见 §2.2.1），创建即拥有，永久持有。
3. **自选池技能**：创建时从**自选技能池**中自选，选定后**锁定**，除非**重新创建角色**否则不可更改。自选数量 = 基数（职业 1 个 / 无职业 3 个）+ 人类加成（+2）；稀有种族的自选数与常见种族一致（优势在种族技与上限，不在自选槽）。
- **自选池设计原则（用户定案）**：池**直接开放给所有角色**——没有种族/职业/等级门槛（龙息谁都能学）。池内技能**功能平价**（治疗/护盾/妨害/AoE/克制/净化各居其位，不比强弱）；可以有强技（弑神者之刃），但**强技能必有强消耗**；**任何池技都不得强于职业招牌技**——池技是「补短板」，不是「抢饭碗」。池内容见 `content-design.md` §5。

### 2.5.1 无职业（Classless）路线
创建角色时也可以选择**无职业**：
- **没有任何职业技**，也**没有职业词条倾向**（词条完全中性随机），初始属性采用中性模板，成长曲线低于任何职业。
- **种族照常生效**：无职业不豁免种族——种族上限修正与种族技（若有）照常应用；「人类 + 无职业」达到自选技数量上限（3 + 2 = 5 个），是自由定制的极端路线（属性双弱）。
- 作为补偿，可从自选技能池**自选更多技能**（例如 3 个，而职业角色只能选 1 个），且随等级解锁的自选技槽位也比职业角色多。
- 定位是「广而不深」的自由定制路线：用**搭配自由度**换**属性强度**。适合喜欢研究技能组合的老玩家，不适合追求数值的新手。
- 无职业角色的强度校准基准：在任何单一属性维度上都弱于对应职业，但可以凑出职业做不到的技能组合（例如同时持有治疗、嘲讽与召唤反制类池技）。

### 2.6 创建流程与限制
1. 玩家选择职业（或无职业）→ 系统**随机抽取种族**（三层稀有度加权：常见 ≈85% / 略微稀有 ≈12% / 最稀有 ≈3%，§11）→ 随机生成词条（方向 × 档位，§2.3）→ 按职业+种族上限+等级(初始1级)+词条计算初始属性 → 从自选池选技（职业 1 个 / 无职业 3 个，人类各 +2）→ 角色诞生。
2. 创建阶段**只能自主确定职业**；种族与词条全随机（重掷同时作用于词条与种族，§2.3）；自选技选定后不可改。
3. 重新创建角色需消耗特定道具（见道具清单），且在**关卡外**才允许。

## 3. 房间与关卡系统

### 3.1 生命周期与难度等级
```
[创建房间(选难度)] → [组队中] → [关卡开始] → [战斗1 → 战斗2 → … → 战斗N] → [结算/逃离]
```
- **创建**：队长发指令开启一个「打怪升级关卡」，指令中**必须选定一个难度等级**。区块链返回**房间号**；或允许队长**自行指定一个不与现有房间冲突的房间号**。
- **难度等级**：地下城按难度分级（例如 D1~D5，或「普通/困难/英雄/噩梦」）。等级由官方配置，可随时调节、可新增。首版五座地下城的命名与世界观（D1 灰烬矿坑 → D5 机神王座）见 `content-design.md` §1。难度决定：
  - 敌人的强度、种类与初始数量；
  - 战斗场数（难度越高，一座地下城内战斗场数越多）；
  - 通关奖励倍率与掉落质量；
  - 救援费数额（难度越高救援费越贵）；
  - 推荐等级与推荐人数、单场战斗回合上限；
  - **入场费**：部分地下城**免费**，部分需支付游戏币入场费（直接销毁，是重要水槽）；
  - **等级门槛**：高难度地下城可设最低角色等级门槛（D5 例如要求 40 级以上），与入场费共同抬高「彩票式刷难度」的入场成本。
- **难度设计原则（核心）**：等级上限把玩家数值封顶后，最难的地下城按**胜率标定目标**设计（用户定案）：
  - **常规词条的满级队伍**（合理职业搭配）：胜率 **40%~50%**——顶配但在词条面上无优势的队伍，攻关仍是掷硬币偏赢的赌局；
  - **拥有两三个超高级词条（4/5 级档，§2.3）的满级队伍**：胜率 **60%~90%**——词条投资显著提升胜率，但**方差刻意放大**（区间宽 30 个百分点）：运气差时仍会翻车，运气好时近乎碾压。超高级词条是「用重掷成本换胜率区间上移」的明确回报，但永远买不到确定性；
  - 低于满级或搭配不合理的队伍：胜率显著低于上述区间，但**不为零**（弱队凭运气通关的爆发性时刻保留）。
  - 运气面构成：随机目标（§4.2）、暴击/闪避掷骰、命中惩罚与绝对命中（§4.9）、魔素争夺、召唤时机、词条随机波动、收益随机分配。
  - 数值策划的目标不是「让强队必胜」，而是**把上述胜率区间标定到位**——强队胜率高、每局有悬念、词条有明确但有限的边际价值。
- **词条价值锚定**：超高级词条（4/5 级档，§2.3）把胜率从 ~45% 抬到 ~60-90% 的边际，即是词条市场价值与重掷期望成本（§7.4）之间互相锚定的数值基础——词条贵到离谱时，其胜率边际撑不起价格，理性买家转向自己重掷；传说档 ≈1.5% 的单发概率让「多传说叠加」近乎不可刷，期望重掷次数随词条质量指数上升。
- **「彩票式刷难度」的期望值约束（数值校准公式）**：对**低强度队伍**，必须有
  `通关概率 × 收益 < 失败概率 × 阶梯救援费 + 入场费 + 每次尝试的 gas 成本`
  即弱队反复掷骰子搏高难度的**长期期望为负**——单次运气通关的爆发性收益保留（这是乐趣），但规模化 Farm 不赚钱（这是经济安全）。该不等式由难度参数（收益倍率、救援费、入场费、等级门槛）联合满足，列入数值仿真验收项。**适用范围**：本公式仅约束低强度队伍；词条投资队（胜率 60%~90%）按词条回报模型衡量（重掷期望成本 vs 胜率边际，§7.4），不受本式约束。
- **组队**：队长召集其他人类；其他人用房间号 **加入房间**，与队长一起连续挑战该难度地下城内的**若干场战斗**。
- **解散**：队长可在**关卡开始之前**解散房间（开始后不可解散，改用「逃离」机制）。
- **房间过期**：创建后一直未开始的房间，闲置超过一定时间（例如 2 小时，官方可调）自动过期关闭——防止恶意抢占/囤积房间号。

### 3.2 队长权限
- 开启 / 指定房间号 + 选定难度、邀请（公告房间号）、解散（仅开始前置）。
- 一场战斗获胜后，发指令**进入下一场战斗**（直至打完整座地下城）。
- 完成某场战斗后，可发指令**让全员逃出整个关卡**（提前瓜分收益）。
- 随时可个人逃离。

### 3.3 人数上限（两类，均可配置）
1. **同时存在的活人数量上限**：关卡内某一时刻最多多少存活角色（被击败者不占活人名额，但可计入总人次）。
2. **加入关卡的总人数上限**：整个关卡生命周期内累计允许多少人加入（含已逃离/被击败者）。

## 4. 回合与战斗系统

### 4.1 回合的两种结束模式（同时支持）
| 模式 | 触发 | 说明 |
|------|------|------|
| 自动回合 | 每 **5 个区块** 或 每 **15 秒**（取先到者） | 需要外部 keeper 服务主动调用链上 `advanceTurn()` |
| 手动回合 | 任何队员/队长发「结束本回合」指令 | 提前结束，加速游戏 |

> 两种模式共存：玩家不想等就手动结束；没人动时由 keeper 兜底推进，避免卡死。
> 防重复推进：合约内对自动/手动做冷却与序号校验。

### 4.2 行动顺序与随机目标
- 每回合开始，按全体在场角色（含怪物）的**敏捷**降序排列行动顺序。
- **任何技能都不允许指定目标**：目标从**合法目标集合中随机**选取——攻击类技能从存活敌人中随机、治疗类从存活我方中随机、多体技能随机选 N 个不重复目标、全体技能命中全部合法目标。目标随机性是运气面的重要组成部分（见 §3.1 难度设计原则），也彻底消除「最优目标集火」的确定性套路，让配队与技能选择（而非目标微操）成为策略核心。
- **权重随机（技能数据层，玩家仍不可指定）**：随机不等于必须均匀——**权重是技能与敌人模板的数据**，玩家无法干预单次抽取：
  - 默认为**均匀随机**（所有合法目标等概率）；
  - 治疗/辅助类技能可声明「**按生命亏空加权**」——残血队友更容易被抽中，满血队友也可能被抽中（治疗不会完全打空，但也不是精准奶血）；
  - 敌人模板可携带「**威胁权重**」——Boss、召唤师被随机命中的概率更高（但仍不保证），普通小怪也可能吃刀；
  - 权重全部设为 1 即退化为均匀随机（保留给追求纯混沌的地下城/技能）。
  这使治疗与输出职业的**期望贡献稳定可估**（排技能时有决策依据），同时保留足够的随机方差（「该奶的没奶到」「大招打小怪了」仍是常见的戏剧性时刻）。
- **嘲讽（Taunt）类技能**是目标选取的另一干预手段：被嘲讽单位的**单体攻击**随机目标被强制重定向到嘲讽者（多体/全体攻击不受嘲讽影响，见 §4.8 平衡约束）——「控场」而非「点杀」。守卫职业由此成为团队里唯一能主动「接火」的角色。
- **多段连击技（一次使用、多次伤害）**：连射/乱舞类技能在一次行动中造成 **N 段独立伤害实例**——**每段独立抽取随机目标（可能重复命中同一目标）**、独立命中掷骰（烟幕/致盲逐段生效）、独立享受伤害上限（每段各钳制一次，总输出 = 段数 × 单段上限）；AP/魔素/弹药按**行动整体**只扣一次（左轮弹雨的弹匣固定消耗，与实际命中段数无关）。「8 段连射全砸同一只小怪」与「8 段分摊全队」都是合法且戏剧性的结果。
- 依次结算每个行动者的技能效果。

### 4.3 技能计划（队列）
- **每回合结束前**，所有队员应决定本回合要使用的技能。
- **只能给自己排技能**：任何指令只对**指令发送者本人的角色**生效，玩家**无法替别人安排或取消技能**（合约层强制校验发送者归属，队长也不例外）。
- 支持**前瞻排程**：任何队员/队长可随时发指令，声明「接下来 N 个回合，每回合使用什么技能」；合约记录该计划，并在后续回合**自动按计划执行**。
- 支持**随时取消**：发指令可清空自己的全部技能计划，下一回合起恢复「手动/空过」。
- **不保证可靠**：合约不强制任何人排技能；未排技能者该回合**空过**（什么都不做）。混乱与运气是乐趣核心，不做任何「未排技能则惩罚/补默认」机制。
- **快捷模板**（客户端层便利，不违反上一条）：群聊里可发 `/排技能 模板=输出`、`模板=攒AP`、`模板=防御` 等一键指令——Bot 把模板**展开成具体的逐回合技能计划**再提交链上，玩家也可随时改。链上从不「自动代打」，模板只是降低打字与记忆成本，保护新人与休闲玩家。

### 4.4 战斗结算
- 回合内按行动顺序，逐一对已记录的技能（或计划中的技能）进行结算。
- **回合快照**：回合结算以推进指令生效那一刻**链上已记录的计划**为准；结算开始后对计划的任何修改只影响后续回合（防止结算期间抢改计划）。
- **资源依次即时扣减**：魔素与 AP 都按行动顺序**先到先得、当场扣减**——轮到某人时资源不足，其技能当场失败空过；不存在预支或为后续行动者预留资源的机制（「抢魔素」博弈因此成立）。
- 技能可能：造成伤害、治疗、增益/减益、消耗/产出魔素与行动点数等。
- 怪物方同样按行动顺序行动，并可能使用需魔素的技能。
- 一场战斗内**全部敌人被消灭** = 该场战斗获胜；整座地下城的全部战斗获胜 = 通关。

### 4.5 动态事件：怪物召唤与中途加入
1. **怪物召唤（新敌人的唯一来源，替代「随机刷怪」）**：
   - **地下城不会每回合随机冒出敌人**。新敌人入场的唯一途径是**怪物方的召唤类技能**。
   - 部分敌人（召唤师、巢穴类怪物）自带「召唤」技能，作为其技能循环的一部分自主施放。
   - 召唤技能**先读取场上信息再决定是否召唤与召唤多少**：典型条件形如「若场上存活敌人数 < 存活角色数 + 2，召唤 min(缺口, 技能召唤上限) 个小怪；否则本次召唤落空」。这从机制上**防止敌人数量无限膨胀**；召唤师的技能循环公开可查（链上透明），「保住随机集火命中召唤师的希望」成为战斗悬念的一部分。
   - 召唤技能同样消耗魔素（与玩家共享同一个房间魔素池，怪物抢魔素是设计特色），也受房间「同时在场单位总数上限」硬约束（超过上限则召唤必然失败）。
   - 玩家方的**反制手段**是控场与生存：嘲讽、控制、驱散能拖住召唤节奏——但无法指定目标集火（§4.2），杀死召唤师要靠随机命中的运气，这正是难度设计原则中「运气占较大因素」的一环。
   - **怪物的种族（§2.2.1）**：敌人模板带种族标签，不影响其数值与技能，仅作为玩家技能种族伤害修正的查表键；战报默认不播报（读链可知，属允许的信息博弈）。
2. **中途加入玩家**：
   - 若关卡内角色**正处于战斗中**：外部新玩家加入后需**延迟若干回合**才「到场」入队。
   - 若关卡内角色**不在战斗中**（例如两场战斗之间的空档）：新玩家**立即加入小队**。

### 4.6 行动点数（AP，Action Point，物理个人资源）
- AP 是**角色个人资源**，与魔素（房间全局资源）相对，二者构成双层资源体系。
- **初始为 0**，且**每场战斗开始时重置为 0**（跨战斗不继承，防止在低难度战斗里囤点、到 Boss 战一次性倾泻的退化打法；该重置规则为可调参数）。
- **大多数物理攻击技能命中后产出 AP**（每次 +1 点或更多，由技能定义）。
- **较强的物理攻击技能消耗 AP**（施放门槛）。
- 每个物理技能都同时定义「AP 消耗」与「AP 产出」两个字段。**即使某技能的产出大于消耗，若施放瞬间 AP 余额不足，技能立即失败，该回合什么都不做**（与魔素不足同规则）。
- 由此形成物理角色的「铺垫 → 爆发」节奏：轻击攒点、重击花点；被控制、空过或技能失败都会打断节奏。AP 不可转移、不可交易、不可用道具充值。
- 魔法技能不产出 AP（它们消耗魔素），两套资源体系互不越界，职业分工由此固化。

### 4.7 伤害上限（Damage Cap）
- **绝大多数技能对每个目标有单次伤害上限**（例如 99999 点）。
- 敌人的生命值**允许远超该上限**，因此超高血量的 Boss 必须靠**多回合、多人、多段输出**磨死，无法被一击秒杀；「秒杀流」在数值上被结构性排除。
- **少数技能没有伤害上限**（通常是高 AP/高魔素消耗的大招或特殊机制技），是对超高血量敌人的「破墙」手段，与资源规划（攒 AP、攒魔素）深度绑定。
- 设计动机：伤害上限是全局**数值天花板**——防止属性膨胀后旧地下城被一刀碾过而彻底报废，也防止「堆一个超级输出角色」的单一最优策略，保证配队多样性。

### 4.8 限时护盾（Shield，限时效果）
- **技术可实现，已纳入技能引擎**：护盾是标准 Effect 原语（技术设计 §2.5 `SHIELD`）——`magnitude` 为护盾量、`duration` 为持续回合数，天然表达「限时护盾」。
- 伤害结算管线：**先扣护盾、再扣生命**——受到伤害时依次消耗身上的护盾层，剩余伤害才落到 HP。
- 护盾**多层独立计时**：不同技能/不同来源的护盾各自倒计时（每回合 duration−1），到时未消耗完的护盾**直接消失**（「限时」的含义：盾不能囤，开盾时机就是决策）。
- 护盾可被驱散（DISPEL 归为可驱散增益），与嘲讽构成攻防博弈。
- **与嘲讽坦克的配合（守卫职业核心循环）**：盾击（嘲讽拉住敌方单体攻击 + 概率眩晕）→ 盾墙（限时大盾）→ 回避（只提回避不减伤，§4.9）——守卫是随机目标体系里**唯一能把不确定性变成确定性的人**：队友被随机攻击的威胁，被守卫主动「接」过来。
- **平衡约束（防双坦吸干全部伤害）**：
  - 嘲讽**只重定向单体攻击类技能**（`RAND_SINGLE_ENEMY`）；多体/全体攻击**不受嘲讽影响**——高难度 Boss 普遍携带 AOE（范围攻击），纯坦克队无法免疫伤害，输出与治疗仍是必需；
  - 嘲讽有持续时间（1~2 回合），需循环续嘲讽，续嘲讽的动作成本与盾/输出竞争；
  - 嘲讽可被敌方驱散（高难度敌人的反制手段），「拉得住吗」本身是悬念。

### 4.9 命中率系统（只降不升 + 绝对命中豁免）
- **设计红线（用户定案）**：命中修正**只有降低方向**——游戏里不存在任何提高命中率的技能、道具或词条。命中经济学只有「变差」与「豁免」两态，没有「变好」；这让命中率惩罚永远是一种**可叠加的混乱源**，而不会被反制buff 抹平。
- **降低命中率的来源**（技能与道具皆有，**玩家和怪物都可使用**）：
  1. **致盲/削弱类**（对敌）：施加于敌方单体或全体，持续若干回合，期间其攻击可能落空；
  2. **烟幕/场地类**（对双方）：作用于**场上全体（敌我双方，含施放者自己）**——「大家都别想打准」的高混乱场面技能，怪物方同样会放；
  3. **回避类**（对己）：提升自身回避——本质是「敌人对我命中率下降」，与致盲在同一公式内叠加。
- **叠加与下限**：多来源惩罚**叠加**，但受**全局命中下限**保护（如最低 5%，官方可调）——惩罚堆满也不会变成绝对打不中；所有命中率效果均可被驱散。
- **绝对命中（豁免掷骰）**：
  1. **对我方的治疗与增益永远绝对命中**——奶不会 miss，增益不会落空（辅助体验的保底）；
  2. **少数特殊攻击技固有绝对命中**：无视一切命中惩罚（含烟幕、致盲、回避），由技能注册时配置，**无法通过任何道具/技能/词条在战斗中获得**。
- **未命中的代价**：伤害与效果全部落空，但已支付的 AP/魔素**不退还**，物理技命中后本可产出的 AP 也拿不到——降低敌人命中率的战术价值，就是让敌人**白花钱空过**（与魔素枯竭空过同属一类「惩罚性空过」，但来源是敌方主动施加）。
- **火枪手专属例外（用户定案，红线的唯一豁口）**：全场唯一的「自我命中提升」机制属于火枪手职业——
  - **鹰眼（Aim）技能**：占用自己的行动位（一整回合不攻击/不放其他技能），为自己施加「**下一回合绝对命中**」状态；
  - 生效期间，该火枪手**自己的所有技能**跳过命中掷骰——穿透烟幕、致盲与一切回避效果（火枪手幻想的核心：全场都在互蒙烟幕时，只有他打得中）；
  - **约束（保持平衡的四道闸）**：① 仅作用于**自己**，无法给队友施加；② 用**行动成本**付费（鹰眼回合输出为零，等效 DPS 并不超标）；③ **可被打断**——鹰眼回合被眩晕/沉默则状态作废，状态挂上后下一回合被眩晕则浪费；④ **不通过任何道具/词条/自选池获得**，纯粹是职业本体；
  - **弹药（第五道闸，用户定案）**：火枪手的**射击类技能消耗子弹**——子弹是可交易的道具（§7.2 弹药类），**两档定价**：左轮弹雨消耗 N 发便宜铅弹、龙击弹消耗 1 发昂贵龙击弹。弹尽时射击技能**失败空过**（同魔素不足语义：该回合什么都不做，且不消耗任何资源）；子弹在扣减时燃烧，**miss 也不退**（枪响子弹就没了——配合鹰眼则基本不会 miss，这正是「确定性按发付费」的含义）。火枪手的绝对命中因此有完整的成本结构：一回合鹰眼的行动费 + 每发子弹的弹药费（左轮弹雨**基础命中率不高**——不先瞄准就是泼水，这是「确定性必须买」的强化表达）；
  - 与技能计划队列天然契合：「鹰眼 → 弹雨」排成两步计划，是前瞻排程玩法的教科书案例。
- 与运气面的关系：命中率惩罚是玩家**主动制造**的运气方差（§3.1）——高难度战斗中，一场双方烟幕互蒙的混战是设计鼓励的名场面；火枪手则是混战中唯一的「确定先生」，与混乱构成对照的戏剧张力。

## 5. 魔素系统（Mana / 全局资源）

- 每座**地下城**内有一种**全局资源「魔素」**：魔素池属于**整座地下城（房间）**，不属于某一场战斗。
- **魔素跨战斗（子关卡）继承**：进入下一场战斗时，魔素池**不清零、不重置**——上一场战斗省下的魔素带到下一场，上一场挥霍掉的同样要还。整座地下城的魔素是一条连续的资源曲线，团队必须在全程尺度上做资源规划（前几场省着放技能，为 Boss 场攒魔素；或前期倾泻求速通，后期承担枯竭风险）。
- AP 与此相反：AP 是**角色个人资源且每场战斗重置**（见 §4.6），个人短期节奏与团队全程规划分层。
- 每回合**自动增加**若干点数（基础增量 + 可能受词条/道具影响）。
- 部分技能（含怪物技能）需要**消耗魔素**才能释放。
- **魔素不足时**：该技能**立即失败**，角色该回合什么都不做（等同于空过）。

> 魔素是地下城级共享资源，制造双层博弈：单场内「是否现在放大招」的即时博弈，与全程「这条魔素曲线怎么分配」的战略规划；抢魔素或留魔素给队友的团队博弈贯穿整座地下城。

## 6. 收益与失败结算

### 6.1 收益记录与发放
- 关卡进行中，**只在后台（链上状态）记录收益，不发放**。
- 仅在以下两种情况**一次性发放**：
  1. **完成整个关卡**（通关整座地下城的所有战斗）；或
  2. **队长在某场战斗获胜后决定全员逃离**（提前结束）。
- 发放对象：**存活的角色**获得收益（游戏币 + 可能的道具）。
- **每人所得随机**：总奖池确定后，**不是精确平分**——合约对每个存活者独立抽取随机权重，按权重分配奖池（期望大致均衡，实际有波动）。运气贯穿到最后一刻：同一队伍里有人分得多、有人分得少，也是战报的谈资。随机分配由 RNG 驱动（§2.3 技术设计），结算交易内一次性完成。
- **中途加入者与开局成员同权**：到场即有资格全额分享（**允许躺赢**）——中途加入是设计鼓励的社交行为（拉朋友下水），不做参与度折扣。

### 6.2 逃离机制（两种，需区分）
| 类型 | 发起者 | 时机 | 后果 |
|------|--------|------|------|
| **个人逃离** | 任何队员或队长 | 关卡内任意时刻 | 发指令后，**若干回合后**该玩家本人逃出**整个关卡**，**无任何收益**；其余人继续 |
| **队长全员逃离** | 仅队长 | **某场战斗获胜后** | 提前结束关卡，**存活者按随机权重分配收益**（§6.1） |

- **队长继承规则（已定案）**：队长**单人逃离或死亡**时，**按加入房间的先后顺序逐个确定继任队长**——从最早加入的成员开始，跳过已逃离/已死亡者，第一个仍在场的成员自动成为新队长，依此顺延。无需任何人手动移交，合约按房间内记录的加入序自动完成。队长单人逃离因此**无需先移交**（规则简单且无争议）；若全房间再无可继任者（全员逃离/死亡），房间即告结束并按对应结算规则处理。
- **战斗间歇期的个人逃离立即生效**：两场战斗之间（无进行中战斗时）发出的个人逃离**立即离场**，无需等待回合；只有在战斗进行中才需等待若干回合。这保证任何队员都不会被「队长不推进」长期绑架——最坏情况是无收益走人，且有时间在超时判负前离场、避免陪葬救援费。
- 队员**不能**触发「全员逃离」。

### 6.3 失败与救援费
- **全队被击败**（所有在场角色生命归零）：无收益，且**全员被倒扣救援费**。扣完后**允许玩家持有负数金额**的游戏币，**负余额没有上限**。
- **部分被击败**（有人存活、有人阵亡）：被击败者**最终不分享任何收益**，且**不扣救援费**；存活者按随机权重分配收益（§6.1）。
- **超时失败**：若超过一段总时间，或某场战斗超过一定回合数仍未获胜，视为**全队失败**，按全队被击败处理（全扣救援费，可负）。
- **阶梯救援费**：同一玩家 24 小时内的连续第 2、3 次……全队失败，救援费**递增**（倍率官方可调）——惩罚「故意送死」式滥用。
- **负债的后果**：负余额（无论多深）玩家**不得创建角色、升级、购买道具/大头菜、创建房间、参与付费入场**，但**仍可加入免费地下城游玩与打工**，其后续收益**优先自动偿还债务**、剩余部分才入账——欠得再深也永远有「打回来」的路径。逃债的唯一方式是弃号，而弃号意味着弃掉角色、履历与全部链上资产（对工作室而言弃号成本极低，因此救援费对工作室的威慑有限——工作室威慑依赖 §7.5 的 gas 成本模型，不依赖救援费）。

## 7. 经济系统

> 本章基于**开放链上经济的现实约束**设计（详见 §7.5）：
> ① **无法阻止无限多账号**（无 KYC，女巫攻击/Sybil 不可防，按账号的限额只是软约束）；
> ② **无法向玩家屏蔽信息**（链上状态任何人可读，一切「隐藏/保密」设计无效）；
> ③ **转移环节半可强制**（所有权变更必经官方合约的 transfer 函数，故与价格无关的转移规则可 100% 强制；只有按成交价抽税不可强制）。
> 设计哲学：**经济规则的唯一目标是「整体不崩溃」**——玩家个体承受混乱与随机是被接受甚至被鼓励的；防的不是玩家的诡计，是系统的坍塌。对抗工作室不靠封号，靠**每次动作的真实 gas 成本 vs 有界产出**的经济学压制。

### 7.1 游戏币（Game Coin）——正式名「烬晶」（Ember Crystal）
> 命名与世界观见 `content-design.md` §2：神力烧剩的暗紫色晶体；本作一切回收（入场费销毁/税收销毁/商店回购销毁）叙事上都是「把烬晶还给灰烬」，与通缩机制同构。聊天指令可简写「烬」；下文仍以系统术语「游戏币」指代。

- 战胜关卡后，存活角色每人分得游戏币；单次通关收益随难度配置。
- **游戏币绝对禁止在玩家之间直接转账**（链上强制：无 transfer 接口，仅合约内部记账，支持无上限负数余额）——这是**可强制**的（游戏币不是代币，只存在于合约 mapping 里，没有场外交易的可能：你无法把一个 mapping 条目「交给」别人，任何「卖游戏币」都只能通过托管共享账号密码实现，而共享即放弃资产安全）。
- 用途：
  - 购买道具（官方商店定价）；
  - 角色升级（等级有硬上限，见 §2.4）；
  - 支付部分地下城的**入场费**（直接销毁）；
  - 进入「大头菜市场」投机（§7.3）；
  - **打工**：每天可执行一次「打工」操作，直接获得少量游戏币（见 §7.1.1）。
- **美元直接购买游戏币**：允许（官方收款渠道），按账号有每日购买限额（软约束——多账号可绕过，但配合等级上限与运气权重，多买币的边际收益快速衰减）。

#### 7.1.2 通道付费（Bot 免费配额与充值）
- 聊天通道（L1）由官方 Bot 代发交易，按**通道分级**收费（详见技术设计 §1.5）：
  - **免费档**：每账号每日**免费动作配额**（很小，官方随时可调；约够一次打工 + 一场短地下城的主要链上动作）。**不付费玩家的游玩次数由此受限**——配额用尽后 Bot 停止代发。**配额口径**：按**产生链上状态变更的 action 计数**（排技能/加入房间/推进回合等）；`查询`、`战报`等只读指令不计入配额。
  - **充值档**：向官方充值 **CFX 或美元**，按动作计费（公开价目表，单价 = 实测 gas × (1+服务费率)），配额内无限畅玩。
  - 也可选包月订阅（官方定价）。
- **CLI 自付通道（L2）与钱包直连（L3）零平台费用、无配额**——付费墙只存在于官方 Bot 通道层，链上合约永远无许可；不想付费的玩家装 CLI 即可无限制游玩（自己付 gas）。
- 商业含义：官方不再无限补贴聊天用户的 gas——免费配额是获客漏斗（支出封顶），重度聊天玩家自然向「充值」或「CLI」分流。

#### 7.1.1 打工（每日零花钱水龙头）
- 每个账号每 24 小时可执行一次「打工」，直接获得少量游戏币。
- **校准原则（关键）**：打工奖励**必须低于执行打工指令本身消耗的 gas 成本**（对 CLI 自付用户）——**打工人性化，打工机器人亏钱**。对 Bot 免费档（L1a）用户，**打工指令计入每日免费动作配额**（占用额度；配额用尽则当日打工也不可用，可走 L1b 充值或 L2 CLI）——工作室开一万个号刷打工，CLI 自付要倒贴 gas，Bot 通道则被配额封顶。
- 打工奖励同样受「负余额限制行为」规则约束（负债者打工所得优先还债）。

### 7.2 道具（Item）
- 战胜关卡后概率/固定获得特殊道具。
- **道具允许玩家之间转账与交易**——每类道具是一个 **ERC-20 道具币**（同质化、可堆叠；decimals=0 整数计数），角色与未来的独特物品是 **ERC-721**；**不使用 ERC-1155**（技术设计 §2.7）。游戏内余额记录在链上「道具金库」内部账本——掉落、商店购买、战斗消耗、队友间递送都在金库内流转（零授权成本）；提取成 ERC-20 钱包形态即可场外/DEX 交易，存回游戏用一笔 **permit 签名交易**完成（无需单独 approve）。
- **不限制道具的使用次数**——道具的强度上限与获取难度由官方数值设计控制（弱道具 + 难获取 = 道具是便利品而非战力核心）。
- **唯一的使用代价：占行动位**（用户定案）——战斗内使用道具必须排进该回合的行动队列，**用了道具，该回合就不能再使用技能**；回合数本身就是天然的使用上限，因此不再设任何次数限制。非战斗状态（地下城间歇、关卡外）使用道具不占行动。
- **弹药类道具是另一回事（不占行动位）**：弹药（子弹等）**不是玩家主动「使用」的道具**，而是**被技能引擎在结算时自动消耗**的耗材——火枪手的射击技能执行时引擎自动从道具金库扣子弹（技术设计 §2.5.2 三重资源门槛的第三重）。因此：弹药消耗**不占行动位**（占行动位的是射击技能本身）；**弹尽即技能失败空过**（该回合什么都不做）；任何人可随时向队友**递弹药**（金库内部转账，一笔极便宜的链上指令，不占任何人的行动、无需对方操作）——「给火枪手递子弹」是设计内的社交协作场面。
- **链上转移不征税**（场外交易可绕过，征税只惩罚走官方市场的诚实用户，形同虚设；官方市场可收**上架费**作为便利性收费，但经济模型**不得依赖**它）。
- **经济制衡全部放在「使用/获取」入口**（合约可强制）：
  - 获取难度：掉落率、商店定价、每日购买限额（软约束）；
  - 强度上限：道具效果数值远低于同级技能（数值层控制）。
- 道具类别（首版）：
  1. **重建角色道具**：重新创建角色（仅关卡外；配合首角色重掷包，重掷的边际价值由其定价封顶——商店价 P 就是「极品词条角色」的价格天花板：工作室卖天价角色会被「玩家自己买道具重掷」套利压制）。
  2. **增加整座地下城魔素道具**（魔素池跨战斗继承，§5）。
  3. **恢复生命道具**。
  4. **挑战券**：无视当日入场次数限制强行进入地下城（消耗性，获取难度即其稀缺度来源）。
  - （预留更多类别，见可扩展性。）

### 7.3 「大头菜市场」：用游戏币炒 CFX（多空对赌模型）
- 玩家用**游戏币**在市场内建立**看涨仓位（买入大头菜）或看跌仓位（卖出空单）**，仓位的盈亏由 **CFX 真实价格**（预言机每若干小时刷新）决定，价格刷新后在群内播报。
- **大头菜（仓位）与游戏币一样不可转账**：仓位是市场合约的内部记账，无 transfer 接口，不能转给他人、不能代持——避免「大头菜变成游戏币的转账媒介」这一整类问题。
- **结算模型（零铸币、池守恒）**：
  - 买入即把游戏币**锁入封闭市场资金池**，平仓时**从池内**按锚定价结算；
  - **多空互为对手方**：CFX 上涨时，看跌仓位的锁定金转移给看涨者；下跌时反之。盈亏在玩家之间转移，**合约永不凭空增发一枚游戏币**；
  - **失衡费（多空不平衡时）**：较重一侧在每次价格刷新时按失衡比例向较轻一侧支付少量失衡费，激励市场自我回归平衡；
  - **点差与平仓费**：开平仓各收点差，**全部销毁**——该市场净通缩；
  - **每日限额**：每人每日开仓总量有限额（软约束，多账号可绕过，但多账号协同操纵一个守恒池无法提取额外价值——多空对赌是零和的，协同多开只是互相对赌，还付点差）。
- **链上透明的必然性**：所有头寸、多空比例任何人可查（无法隐藏），市场因此是**纯公开信息博弈**——这被视为特性而非缺陷：群友可以围观大户仓位，形成社交话题。刷新前根据链下实时 CFX 价格抢先布仓，是**设计内的玩法**（预测下个锚定价），不是漏洞——所有人都看得到同样的链下信息，市场内部零和。

### 7.4 角色出售（角色交易规则）
- 角色是官方 NFT 合约（ERC-721）上的资产，可自由出售/转让。**关键合约事实：链上改变角色 owner 的唯一途径就是调用该 NFT 合约的 transfer 系函数**（approve/setApprovalForAll 只是授权，不转移所有权；不存在绕过合约改 owner 的路径）——因此**与价格无关的转移规则可以 100% 在 transfer 函数内强制执行**：
  1. **等级重置为 1**：直接写在 transfer 函数里——所有权一变，等级即重置（无需事后检查）；
  2. **战斗中禁止转移**：角色在房间内（未结算离场）时 transfer 直接失败——战斗中不允许易主（保护弹药归属、技能计划与战斗状态的一致性），个人逃离/结算离场后即可自由交易；
  3. **自选池技锁定随角色转移**：买家无法更改已选池技；
  4. 词条、履历、职业**随角色完整转移且完全公开**（链上可读）：优质词条角色会被市场正确定价，官方不试图阻止。
- 不可强制的只有**按成交价百分比抽税**（成交价与支付可完全留在链下/场外），本设计不依赖它。
- **极品角色的价格天花板**：由**期望重掷成本**锚定——重掷概率分布公开（链上可算），硬极品（**稀有种族 × 传说档词条**，市场流通层供应率 <0.5%，`content-design.md` §9）的期望重掷次数 × 重掷道具商店价 + gas 构成理性买家的成本上限；工作室批量重掷的成本结构与散户相同（同一商店价），竞争会把极品号价格压到边际成本附近，规模化利润空间极薄——**词条档位长尾（传说 ≈1.5%）与种族三层压低（最稀有 ≈3%）正是这套锚定的执行层：两个随机维度各自变稀，期望重掷次数相乘地上涨**。
- 设计意图：官方**不阻止**角色交易市场（也阻止不了），而是把它约束成「词条抽奖结果的市场」，其价值上限被重掷期望成本锚死。

### 7.5 开放链上经济的现实约束与对策（安全边界声明）

本节明确「我们防什么、防不了什么、靠什么活」。**经济规则的唯一底线是「整体不崩溃」——玩家个体承受混乱与随机是被接受的（甚至被鼓励）**：

| 开放链上事实 | 防不了什么 | 现实对策 |
|---|---|---|
| **无限账号（Sybil）** | 按账号的限额/配额被多号稀释；小号弃债 | ① 每次动作的 gas 成本 > 该动作的期望可变现产出（CLI 自付通道天然如此）；② Bot 代付通道按账号动作配额封顶补贴总量；③ 可转移资产（道具/角色）的单位价值有硬天花板（强度上限 + 重掷期望成本锚），规模化刷号的期望利润低于规模化 gas 成本 |
| **链上信息全透明** | 词条/仓位/敌人配置/掉落率保密 | 全部当作公开信息设计博弈（多空公开对赌、技能循环公开可查、重掷概率公开可算）；不依赖任何「隐藏」机制 |
| **转移环节：半可强制** | 按成交价百分比抽税（价格可藏链下） | **所有权变更必经官方 NFT/ERC-20 合约的 transfer 函数**——与价格无关的规则（等级重置、固定费、冷却、熔断）可在 transfer/`_update` 钩子内 100% 强制；本设计用到的强制点：角色转移重置等级（§7.4）。道具保持零转移限制（制衡在获取/强度层） |
| **游戏币与大头菜不可转账（对我方有利的强强制）** | ——（内部账本，无 transfer 接口，场外交易不存在；「卖币」只能托管账号密码=放弃资产安全） | 所有主水龙头收益（打工/通关收益）沉淀在不可转账层；美元购买只走官方商城（单向入金，受每账号日限额软约束）；道具是唯一可流出资产，其价值被强度上限封顶 |

**经济不崩溃的判据（可检验）**：① 多空市场与奖池支付全部来自玩家锁定/官方配置的池，合约永不超发（合约层可审计）；② 每账号每动作的期望可变现产出 < gas 成本（数值层校准，§3.1 / §7.1.1）；③ 可转移资产单件价值有硬天花板（道具强度 + 重掷期望成本）。三者成立时，无论多少账号、多少外部市场，游戏内经济自成闭环，通胀被锁死在不可转账层内，不影响链下世界，也不会反噬玩法。

## 9. 可扩展性与二次开发

因为运行在区块链上，游戏逻辑以**可升级/可组合**的智能合约形式存在，天然支持：
- **新职业 / 新词条 / 新技能**：通过注册表（Registry）合约追加，无需改核心。
- **新道具类别**：道具合约预留类型扩展位。
- **新地下城与怪物**：关卡参数（敌人模板、回合数上限、魔素增量）数据化，可由运营或治理下发。
- **随机性扩展位**：RNG 经路由器按用途分发（§2.3 技术设计），未来可低成本引入更多随机玩法——随机事件关卡（「本战斗全场魔素翻倍/减半」）、随机词条变异、随机天气/地形修正等。**设计许可：在战斗与玩法层增加随机是被鼓励的方向**（经济层保持三条不崩溃判据即可，见 §7.5）。
- **玩家/社区自建功能**：任何人可读取链上事件与状态，构建自己的前端、分析面板、甚至基于公开接口写「机器人插件」（例如自动排技能助手、收益计算器）。合约只负责权威结算，表现层完全开放。

## 10. 规则歧义澄清（把原始描述里的模糊点定下来）

为避免后续开发扯皮，对原始玩法描述做如下明确：

1. **解散 vs 逃离**：队长**仅在关卡开始前**可解散房间；开始后只能用「个人逃离 / 全员逃离」结束参与。
2. **两种逃离不是一回事**：个人逃离（任何人、任意时刻、无收益、延迟若干回合离场）≠ 队长全员逃离（仅某场战斗获胜后、存活者随机权重分配收益）。
3. **队长继承**：队长单人逃离或死亡时，按加入房间的先后顺序逐个确定继任队长（跳过已逃离/已死亡者），无人可继任则房间结束。
4. **「同时存在的活人数量」与「总加入人数」是两个独立上限**，分别配置。
5. **战斗中 vs 非战斗中**：以「当前是否存在进行中的战斗且有存活敌人」定义战斗状态，决定中途加入者是立即入队还是延迟到场。
6. **魔素不足 = 该技能失败且空过**，不触发其他惩罚。
7. **救援费允许负数**：游戏币余额可为负，作为内部账本允许。
8. **收益发放仅两次触发点**：通关全部 / 队长在某场战斗获胜后全员逃离；部分被击败者不分享且不扣费；发放金额按随机权重分配（期望均衡、实际波动），中途加入者与开局成员同权。
9. **超时判定**：需分别配置「整个关卡总时限」与「单场战斗回合数上限」。
10. **新敌人的唯一来源是怪物召唤技能**，没有独立的随机刷怪机制；召唤技能读取场上双方存活数量决定召唤量。
11. **每个玩家只能给自己排技能**，合约按指令发送者校验归属；队长无权代排。
12. **任何技能都不能指定目标**：单体/多体技能的目标从合法集合中随机抽取（可按技能/敌人模板数据加权），全体技能命中全部；嘲讽是唯一的目标干预手段。
13. **负余额无上限**；负债者受限的行为集见 §6.3。
14. **开放链上约束**（无限账号 / 信息不可屏蔽 / 转移环节半可强制）及其对策见 §7.5——设计不依赖任何做不到的强制；**游戏币与大头菜均不可在玩家间转账**（美元可经官方商城单向购入游戏币）。
15. **经济规则的唯一底线是整体不崩溃**：混乱、随机、运气都是玩法的一部分，规则不为个体公平性服务。
16. **命中修正只降不升**（§4.9）：降低命中的技能/道具敌我皆可用、可同时作用于双方；对我方治疗与增益永远绝对命中；少数特殊攻击技固有绝对命中；不存在任何通用提高命中率的效果——**唯一例外**是火枪手职业的「鹰眼」（自用、职业专属、行动付费、可被打断）。
17. **种族是第二重命运抽签**（§2.2.1）：创建时随机（三层稀有度加权）、永久不可改、影响属性上限；非人类种族有种族技，人类以额外自选池技补偿；怪物种族是纯风味标签（不影响怪物数值），仅作为玩家技能种族伤害修正的查表键（修正数值逐技能登记，引擎无内置克制逻辑）。
18. **词条是方向 × 档位的抽签**（§2.3 / `content-design.md` §6）：正面/双刃/负面三向 + 1~5 级长尾档位（传说档极小概率、非常显著地加强或削弱）；**负面词条不可单洗**，只能随整体重掷（命运骰子=词条+种族 / 重生卷轴=整个角色）消散；全负面角色触发无数值的隐藏称号「天弃者」；职业适配与技能选择不计入精品概率漏斗（玩家先定职业、重掷筛种族、自选技无门槛，`content-design.md` §9）。

### 11.1 数值仿真验收清单（经济安全验收项，subagent 审阅产出）
以下不等式/对比是**上线前数值仿真的必过项**（满足即安全，不满足则调参数而非改设计）：
1. **词条投资期望闭环**：在词条胜率区间 **75%~85% 的高发配队**（而非只测 60%/90% 两个极端）下，`词条边际胜率 × 奖池 − 边际救援费 − 重掷道具期望成本 − gas ≤ 0`——若为正，调高重掷道具价或压低该区间奖池。
2. **火枪手校准**：同一 D4/D5 下对比「含火枪手队 vs 普通满级队 vs 词条队」的胜率与期望收益——火枪手不得使队伍显著超过同词条水平（确定性输出是定位优势，不是数值优势；超出则下调火枪系技能威力或**上调子弹定价**——弹药是火枪手的常态化成本，其价格是校准杠杆之一）。
3. **道具行动位预算**：同一 Boss 下「满道具方案 vs 无道具方案」对比——道具替代技能的净收益必须为负或近零（道具换生存 = 少一轮输出，数值上应接近等价交换；若道具明显占优则下调道具强度）。
4. **蹭车期望**：免费地下城「中途加入躺赢」的期望收益 ≤ 加入动作的 gas/配额成本（保持躺赢定案不变，靠免费房低奖池 + 动作成本压制；若某免费房期望为正，下调其奖池）。
5. **L1a 打工补贴上限**：补贴总量 = L1a 配额 × 日活账号数 × 打工 gas——作为获客成本预算项管理，超过预算即收紧配额（打工与战斗互斥等硬手段为备选项，默认不启用）。
6. **角色市场供应压制**：`硬精品率 × 期望售价 −（创建 + 重掷期望次数）× 单位成本（gas + 重掷道具价）≤ 0`——若为正（工作室批量刷号有利可图），压低传说档概率、上调重掷道具价或下调硬精品强度，三杠杆任选（`content-design.md` §9 硬精品分层）。
